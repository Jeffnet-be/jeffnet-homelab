# Findings

One file per finding. Each is dated to when it was found, written in the past tense, and published
once it was closed.

The format is deliberate:

1. **The symptom** — what was actually observed, including what it looked like at first glance.
2. **The chain** — in the order it was unravelled, not the order that reads best. Most of these were
   only reachable through the finding before them.
3. **The cause.**
4. **What changed.**
5. **The general lesson** — what this stops being a story about.

Wrong theories stay in. A write-up that only contains the correct path is a worse teaching document
and a less honest one, and the dead theories are usually where the interesting reasoning happened.
